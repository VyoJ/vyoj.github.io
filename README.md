# vyoj.github.io

Source for my personal website: [vyoj.github.io](https://vyoj.github.io).

Built on [al-folio](https://github.com/alshedivat/al-folio), a Jekyll starter for academic
sites. The upstream project README is kept alongside this one as
[`README-al-folio.md`](README-al-folio.md), and its documentation lives in
[`docs/`](docs/README.md).
